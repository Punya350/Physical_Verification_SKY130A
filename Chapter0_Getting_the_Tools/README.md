# Chapter 0: Getting the Tools

## Objective
Set up and verify the open-source EDA tools required for physical verification using the SKY130A Process Design Kit (PDK).

## Tools Required
- **SKY130A PDK:** Provides process technology files and device models.
- **Magic:** VLSI layout editing and design rule checking.
- **ngspice:** Circuit simulation.
- **Xschem:** Schematic capture and netlist generation.
- **Netgen:** Layout Versus Schematic (LVS) comparison.
- **open_pdks:** Configures PDK support for compatible EDA tools.
